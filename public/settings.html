LLM integration

The Gemini API key and model IDs used for every stage of the pipeline.

Up to 5 Gemini API keys. When the key in use gets rate-limited (HTTP 429), Verso automatically rotates to the next one — no restart needed. Only Key 1 is required.

Three model-agnostic tiers — name whatever model IDs you like, the pipeline only ever refers to the tier. Draft (the call that determines detector evasion) tries main → flash → lite in order. Extract/Guard (mechanical) tries lite → flash. Each step falls back automatically on error or rate limit.

Generation parameters

Temperature and top-p per pipeline stage. Higher temperature on the draft stage is what produces real sentence-length variance.

Stage A — Extract prompt

Compresses input into content-only notes, discarding the original's sentence structure.

Stage B — Draft prompt

Writes fresh prose from the notes. Shared skeleton across every writing style — {{STYLE_INSTRUCTION}}, {{CONTRACTIONS_RULE}}, and {{PUNCTUATION_RULE}} are filled in per-style below; {{INTENSITY_INSTRUCTION}} and {{BANNED_PHRASES}} from Light/Balanced/Thorough and the selected style. Keep all five placeholders somewhere in the text.

Stage C — Guard prompt

Checks the draft against the original and fixes only rule violations. Shared skeleton — {{BANNED_PHRASES}} and {{STYLE_RULES}} (ending rule, symmetry check, extra checks) come from the selected style below.

Writing styles

Stage B and C both pull from whichever style the author picks — a blog voice's AI-tells aren't an academic paper's or a legal memo's, so each style has its own voice instruction, banned-phrase list, and guard rules rather than sharing Author's. Pick a style below to view or edit it; switching styles keeps your unsaved edits to the one you're leaving.

Intensity levels

Appended to the draft prompt in place of {{INTENSITY_INSTRUCTION}}, depending on the slider the author picks.

Your personal banned phrases

Comma-separated. Layered on top of whichever style's own list is active, for every style — use this for words you want banned everywhere, not a style-specific tell. Empty by default so it never contradicts a style's own list (e.g. "furthermore" is banned for Author but normal usage in Academic).
